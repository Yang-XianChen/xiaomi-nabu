# 电源按键与合盖行为改造 — 配置文档

> 适用设备：具备电源键、合盖开关和背光设备的 Linux 平板/笔记本
> （开发目标：Xiaomi Pad 5 / Ubuntu / GNOME Wayland / systemd）。
> 文中出现的设备名与输入事件编号均为示例，守护进程会自动探测，不依赖固定编号。

## 1. 目标

- 短按电源键：仅切换屏幕开关，不再关机、不弹关机菜单。
- 合盖：仅关屏；开盖：仅开屏，不再挂起/休眠。
- 屏幕关闭必须是“真正关闭内容”，而非只关背光（避免打光后看到内容残影）。
- 开屏后触摸/鼠标映射立即恢复正常。
- 系统挂起/休眠唤醒后自动恢复背光（唤醒即亮屏）。

## 2. 最终行为

| 事件 | 行为 |
| --- | --- |
| 短按电源键 | 屏开 → 屏关并启动 15 秒挂起倒计时；屏关 → 屏开（恢复原亮度）并取消倒计时 |
| 键盘按键 / 鼠标移动、点击 / 触摸板手势（屏幕关闭或已息屏时） | 开屏并刷新触摸/指针设备（同时取消挂起倒计时） |
| 合盖 | 关屏并启动 30 分钟挂起倒计时（若已有电源键倒计时则保持原倒计时，不重复关屏） |
| 开盖 | 开屏（恢复原亮度）并取消挂起倒计时 |
| 长按电源键 | 软件层忽略（硬件 PMIC 级强制断电不受软件控制，见第 7 节） |
| 挂起/休眠后唤醒 | 自动恢复背光（唤醒即亮屏），并重置挂起倒计时状态 |

## 3. 环境要求

- Linux + systemd；GNOME Wayland 推荐（合成器 D-Bus 通道：`org.gnome.Mutter.DisplayConfig`）。
- 电源键输入设备（`KEY_POWER`）、合盖开关输入设备（`SW_LID`）。
- 背光 sysfs 设备（如 `ktz8866-backlight`）。
- 可选：Novatek 触摸/显示控制器（启用自动恢复循环）。

## 4. 变更总览

| 文件 | 作用 | 状态 |
| --- | --- | --- |
| `/etc/systemd/logind.conf.d/10-screen-toggle.conf` | logind 忽略电源键与合盖事件 | 由安装脚本写入 |
| `/usr/local/sbin/screen-toggle-daemon` | 常驻守护（Rust）：监听按键/合盖并驱动屏幕开关 | 由安装脚本写入 |
| `/etc/systemd/system/screen-toggle.service` | 守护进程服务 | 由安装脚本启用 |
| `/etc/systemd/system/screen-toggle-resume.service` | 挂起/休眠唤醒后的背光恢复钩子 | 由安装脚本启用 |
| GNOME 电源设置 | 电源键与合盖动作改为“无动作” | 安装脚本尽力设置，也可手动设置 |

## 5. 配置详解

### 5.1 systemd-logind：忽略电源键与合盖

`/etc/systemd/logind.conf.d/10-screen-toggle.conf`：

```ini
[Login]
HandlePowerKey=ignore
HandlePowerKeyLongPress=ignore
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore
LidSwitchIgnoreInhibited=yes
```

### 5.2 GNOME 电源设置

以图形会话用户身份执行：

```bash
gsettings set org.gnome.settings-daemon.plugins.power power-button-action nothing
gsettings set org.gnome.settings-daemon.plugins.power lid-close-ac-action nothing
gsettings set org.gnome.settings-daemon.plugins.power lid-close-battery-action nothing
```

### 5.3 屏幕开关守护服务

守护程序 `/usr/local/sbin/screen-toggle-daemon`（Rust 编译）功能：

- 自动探测电源键（`KEY_POWER`）、合盖开关（`SW_LID`）、键盘
  （`ID_INPUT_KEYBOARD`）和鼠标/触摸板（`ID_INPUT_MOUSE` /
  `ID_INPUT_TOUCHPAD` / `ID_INPUT_POINTINGSTICK`）的输入设备节点，不依赖
  固定 event 编号；每 3 秒与系统比对一次，后连接的蓝牙键盘/鼠标自动纳入
  监听，断开的设备自动剔除。
- 关屏流程：
  1. 以会话用户身份调用 `gdbus`，设置 `org.gnome.Mutter.DisplayConfig.PowerSaveMode = 1`
     （合成器将 DRM 连接器置为 DPMS Off / disabled，面板彻底停止输出内容，消除残影）；
  2. 保存当前用户亮度；
  3. 背光写入 `0`。
- 开屏流程：
  1. `PowerSaveMode = 0`（恢复显示输出），最多重试 3 次，并以真实 DPMS 状态
     校验是否真的点亮；若合成器仍未点亮，**不把屏幕标记为已开**，下一次
     按键/合盖开合会重新走完整开屏流程；
  2. 恢复显示输出后先保持背光为 `0` 约 0.7 秒，待 DSI 面板/触摸控制器初始化
     完成后再恢复亮度；
  3. 恢复亮度优先调用 Mutter `SetBacklight`（保持 GNOME 亮度设置同步），
     Mutter 拒绝的值（如 0）或调用失败时回退直接写 sysfs；写入后校验一次，
     未生效自动重试；
  4. 屏幕点亮后在后台对触摸屏/触控笔、鼠标/触摸板执行 udev remove/add，
     让合成器重算触摸映射，不占用开屏时间；
  5. 开屏后再次检查 DPMS，若合成器立即重新熄灭则自动再点亮一次。
- 挂起倒计时：
  - 电源键关屏：15 秒后若系统仍未进入挂起，自动执行 `systemctl suspend`；
  - 合盖关屏：30 分钟后若系统仍未进入挂起，自动执行 `systemctl suspend`；
  - 若已有倒计时时合盖，不重复关屏、不重置倒计时；
  - 充电状态下挂起控制禁用：电源键/合盖只关屏，不启动挂起倒计时；
  - 倒计时期间任何开屏信号都会亮屏并取消倒计时。
- 键盘/鼠标/触摸板唤醒：屏幕关闭或 GNOME 已息屏时，任意按键、鼠标移动
  （≥ 2 个单位）或点击、触摸板手势都会触发开屏；合盖状态下不唤醒。
  关屏后 2 秒内忽略指针唤醒（电源键、键盘不受影响），避免按电源键时
  手部移动导致屏幕立即回亮。
- 外部唤醒恢复亮度：GNOME 自动熄屏被键盘/鼠标解除后，若背光仍停留在
  `idle-dim` 压暗值或 0，守护进程会自动恢复用户亮度（仅恢复亮度，不重复
  完整开屏流程），避免屏幕“看似没唤醒”、再按电源键反而变成关屏。
- 电源键防抖：开屏后 1 秒内再次按键被忽略，避免“开→关”来回切换；关屏后
  防抖立即重置，马上再按电源键即可唤醒。
- 开屏过程较慢（例如面板恢复循环）时，排队等待的电源键事件按事件时间戳
  判断为“开屏前按下”而忽略，避免开屏完成后又被立刻关屏。
- 用户亮度跟踪：屏幕点亮时持续记录 sysfs 亮度，并按 GNOME
  `idle-brightness` 设置识别 `idle-dim` 压暗值（默认 30%），压暗值不会
  覆盖用户亮度；用户调整亮度后状态文件自动更新。
- 系统唤醒后的第一次开屏直接以一次完整 blank→unblank 循环替代常规
  unblank（背光保持 0）：本类面板在唤醒后即使固件日志显示成功仍可能黑屏，
  完整开关一次才能可靠点亮。
- 所有外部命令调用（gdbus / loginctl / udevadm / journalctl）都有超时保护，
  防止某个 D-Bus 调用卡住导致守护进程永久阻塞。
- 收到 `SIGUSR1`（唤醒钩子触发）时：恢复背光并同步开关状态。

### 5.4 唤醒恢复钩子

`/etc/systemd/system/screen-toggle-resume.service`：

```ini
[Unit]
Description=Resync display backlight after system resume
After=suspend.target hibernate.target hybrid-sleep.target suspend-then-hibernate.target

[Service]
Type=oneshot
ExecStart=/usr/bin/systemctl kill --kill-whom=main -s SIGUSR1 screen-toggle.service

[Install]
WantedBy=suspend.target hibernate.target hybrid-sleep.target suspend-then-hibernate.target
```

- 钩子只向守护进程主进程发送 `SIGUSR1`（`--kill-whom=main`），不会误杀
  正在执行的 loginctl / runuser / gdbus 子进程。
- 唤醒时先读取合盖开关真实状态：若合盖处于闭合，保持屏幕关闭并立即重新
  挂起（同一 60 秒窗口内最多 3 次，防止合盖唤醒死循环）。
- 唤醒后无论屏幕是否已被合成器点亮，都会在后台刷新触摸/指针设备。

## 6. 工作原理

```text
电源键按下 ──> 电源键输入设备产生 KEY_POWER 事件
合盖/开盖 ──> 合盖开关输入设备产生 SW_LID 事件
键盘/鼠标 ──> 相应输入设备产生按键/移动事件
        │
        ▼
screen-toggle-daemon（root，systemd 服务）
        │
        ├── 关屏：mutter PowerSaveMode=1 → 背光=0
        ├── 开屏：PowerSaveMode=0 → 恢复亮度 → 后台刷新输入设备
        └── SIGUSR1（唤醒）：恢复背光 + 同步状态

挂起/休眠唤醒 ──> screen-toggle-resume.service ──> SIGUSR1
```

### 6.1 持续花屏的自动恢复

本类设备的显示链路（DSI 面板 + 触摸控制器）在 DPMS 关闭/恢复后偶尔初始化
不完整，表现为触摸固件加载失败或面板花屏，直到再完整开关一次屏幕才恢复。

守护进程处理方式：

1. 每次开屏后保持背光为 `0`，先等待显示链路稳定；
2. 系统挂起唤醒后的第一次开屏直接以一次完整 `blank → unblank` 恢复循环
   替代常规 unblank（背光仍为 `0`），即使内核未报错也执行；
3. 同时检查该次开屏时间窗口内的内核日志（以“最终失败”为准，忽略固件重试）；
4. 若检测到初始化失败记录，继续执行最多 2 次 `blank → unblank` 恢复循环，
   任一次成功即恢复亮度；全部失败才恢复亮度并记录日志。

## 7. 已知问题与注意事项

1. **无图形会话时**（如 GDM 登录界面）：无法调用合成器 D-Bus 接口，退化为
   仅关闭背光（可能仍有残影）。
2. **硬件长按电源键**：PMIC 级强制断电/复位属于硬件行为，无法通过软件关闭。
3. **触摸映射问题**：显示输出禁用/恢复后合成器可能保留旧触摸映射；已通过
   开屏时自动重加输入设备缓解，若仍异常可尝试重启图形会话。
4. **自动挂起**：未禁用系统自动挂起；唤醒后由钩子恢复背光。
5. **GNOME 自动熄屏交互**：GNOME 空闲自动熄屏同样使用 `PowerSaveMode=1`；
   守护进程通过后台轮询识别，外部输入唤醒后自动刷新输入设备。
6. **面板稳定性**：显示/触摸驱动存在不稳定现象，每次开关屏都会触发触摸
   控制器挂起/恢复与固件重载；建议避免短时间内快速连续开关屏。
7. **自动恢复的检测边界**：若某次花屏没有任何内核报错记录，守护进程无法
   感知，仍需要手动开关一次屏幕。
8. **磁吸键盘**：挂起期间可能由硬件断电，唤醒后需要物理重新吸附。

## 8. 验证方法

服务状态：

```bash
systemctl status screen-toggle.service
systemctl is-enabled screen-toggle.service screen-toggle-resume.service
journalctl -u screen-toggle.service -n 50
```

屏幕状态（路径按实际设备替换）：

```bash
cat /sys/class/drm/card0-DSI-1/dpms
cat /sys/class/backlight/ktz8866-backlight/brightness
```

GNOME 设置确认：

```bash
gsettings get org.gnome.settings-daemon.plugins.power power-button-action
gsettings get org.gnome.settings-daemon.plugins.power lid-close-ac-action
gsettings get org.gnome.settings-daemon.plugins.power lid-close-battery-action
```

模拟电源键/合盖事件（设备节点按 `journalctl -u screen-toggle.service` 日志
中自动探测到的实际节点替换）：

```bash
python3 - <<'PY'
import os, struct, time
fmt = struct.Struct("<qqHHi")
def ev(t, c, v): return fmt.pack(0, 0, t, c, v)
def inject(path, events):
    fd = os.open(path, os.O_WRONLY)
    try:
        for e in events:
            os.write(fd, e); os.write(fd, ev(0, 0, 0)); time.sleep(0.05)
    finally:
        os.close(fd)
inject("/dev/input/event0", [ev(1, 116, 1), ev(1, 116, 0)])   # 电源键（示例）
inject("/dev/input/event2", [ev(5, 0, 1)])                     # 合盖（示例）
inject("/dev/input/event2", [ev(5, 0, 0)])                     # 开盖（示例）
PY
```

## 9. 卸载 / 回滚

```bash
sudo systemctl disable --now screen-toggle.service screen-toggle-resume.service
sudo rm -f /etc/systemd/system/screen-toggle.service /etc/systemd/system/screen-toggle-resume.service
sudo rm -f /etc/systemd/logind.conf.d/10-screen-toggle.conf
sudo rm -f /usr/local/sbin/screen-toggle-daemon
sudo rm -rf /var/lib/screen-toggle
sudo systemctl daemon-reload
sudo systemctl restart systemd-logind

# 恢复 GNOME 默认电源动作
gsettings reset org.gnome.settings-daemon.plugins.power power-button-action
gsettings reset org.gnome.settings-daemon.plugins.power lid-close-ac-action
gsettings reset org.gnome.settings-daemon.plugins.power lid-close-battery-action
```

回滚后电源键恢复默认关机行为、合盖恢复默认挂起行为。
