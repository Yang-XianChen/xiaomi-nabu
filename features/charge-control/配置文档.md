# charge-control 配置文档

## 行为规则

| 电量（%） | 动作 |
| --- | --- |
| `> 75` | 停止充电（standby） |
| `< 50` | 允许充电（switching） |
| `50 ~ 75` | 保持当前状态 |

阈值为严格比较：75% 整点不停止，76% 才停止；50% 整点不恢复，49% 才恢复。

## 命令行参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--stop <N>` | 75 | 停止充电阈值 |
| `--start <N>` | 50 | 允许充电阈值 |
| `--interval <N>` | 20 | 电量常规检查间隔（秒，最小 5） |
| `--watch-interval <N>` | 2 | 充电器插拔监测间隔（秒，最小 1） |
| `--battery <PATH>` | 自动查找 | 电池 sysfs 目录 |
| `--charger-psy <PATH>` | ln8000-charger | 充电器 power_supply 目录 |
| `--i2c-dev <DEV>` | /dev/i2c-1 | I2C 设备 |
| `--i2c-addr <ADDR>` | 0x51 | LN8000 芯片地址 |
| `--once` | 关 | 只执行一次检查后退出 |
| `--status` | 关 | 只读显示当前状态后退出 |
| `--dry-run` | 关 | 只打印动作，不写寄存器 |
| `--no-restore-on-exit` | 关 | 退出时保持当前状态 |
| `--verbose` | 关 | 输出更详细日志 |

## 修改服务参数

```bash
sudo systemctl edit charge-control
```

覆盖 `ExecStart`：

```ini
[Service]
ExecStart=
ExecStart=/usr/local/sbin/charge-control --stop 80 --start 60 --interval 15
```

```bash
sudo systemctl daemon-reload
sudo systemctl restart charge-control
```

## 服务管理

```bash
systemctl status charge-control
journalctl -u charge-control -f
systemctl stop charge-control    # 停止服务（默认恢复允许充电）
systemctl start charge-control
systemctl disable charge-control # 取消开机自启
```

服务收到 `SIGTERM`/`SIGINT` 时，默认在充电器接入的情况下恢复“允许充电”；
如希望停止服务后保持停止充电，在 `ExecStart` 追加 `--no-restore-on-exit`。

## 卸载

```bash
sudo systemctl disable --now charge-control
sudo rm /etc/systemd/system/charge-control.service
sudo rm /usr/local/sbin/charge-control
sudo systemctl daemon-reload
```

## 注意事项

- 必须使用 root 运行，`/dev/i2c-*` 默认仅 root 可访问；
- 仅适配 LN8000 充电芯片（小米平板 5）；移植到其它硬件前需确认寄存器定义；
- 拔插电源后内核驱动会立即恢复充电，本服务约 2 秒内重新接管；
- `ln8000-charger/status` 显示的是驱动内部标志，真实模式以 `SYS_STS` 与
  `qcom-battery/status` 为准。
